# The piper based server
It uses [piper-tts](https://github.com/OHF-Voice/piper1-gpl) for inference and pyaudio for playing it

## Instalation
1. pip install piper-tts (It's kinda hard rn on Termux), flask and pyaudio (It also requires portaudio be installed in your package manager)
2. Download a piper voice and try it out [with this guide](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/CLI.md)
3. Run main.py and remember the ip it says
